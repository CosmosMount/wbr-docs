# WBR Docs

偏置并联构型轮腿机器人的建模、控制、仿真与实验文档。

- 在线站点：<https://cosmosmount.github.io/wbr-docs/>
- 内容格式：Obsidian Markdown
- 发布引擎：`@obsidian-githubpage/cli@1.0.9`

仓库根目录可以直接作为 Obsidian Vault 打开。GitHub Pages Workflow 会读取 `.githubpage/site.json` 中的精确引擎版本，并在 runner 临时目录安装 CLI；本仓库不需要 `package.json` 或 `package-lock.json`。

`draft: true` 或 `publish: false` 只会从网站构建中排除页面，不代表内容保密。
